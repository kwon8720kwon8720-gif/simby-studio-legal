The Website URL opens the live Simby Studio publisher.
It is a fully developed product, not a marketing landing page and not a login wall.

On first load the reviewer can:
1. See the connected TikTok account (nickname, username, max duration from creator_info)
2. Select a video and preview it. Simby Studio adds no watermark.
3. Edit the title.
4. Choose privacy. There is NO preselected default.
5. See Comment / Duet / Stitch all OFF by default.
6. See commercial disclosure OFF by default. Branded content cannot use "Only me".
7. Read Music Usage Confirmation (and Branded Content Policy when disclosure is on).
8. Tick express consent. The Post button stays disabled until video + privacy + consent are complete.
9. Submit through the TikTok Content Posting API and watch publish/status.

Terms of Service and Privacy Policy links are visible in the gold bar under the header and again in the footer, without opening a menu.

This is a public creator product. It publishes the creator's own gameplay clips to the creator's own TikTok account. It is not for private personal use only, and it does not redistribute third-party content.

Scopes:
- user.info.basic : show the destination account and posting limits
- video.upload    : transfer the selected file for preview
- video.publish   : publish after express in-app consent
